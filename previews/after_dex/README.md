# 도감 이후 귀가·202번도로

플레이어 집에 돌아가면 엄마가 파티를 회복하고 모험노트를 줍니다.
이어 단짝친구의 엄마가 전해줄 물건을 맡깁니다. 마을 북서쪽 흙길이
202번도로로 이어지며, 표지판은 길 안내를 제공합니다. 마을·호수 필드·202번도로는
같이 불러와 야외 경계에서 페이드나 순간이동 없이 같은 플레이어와 카메라를 유지합니다. 달리기는 처음부터 사용 가능합니다.

202번도로에서는 조수가 비버니를 약화하고 포획하는 시범을 보인 뒤
몬스터볼 5개를 줍니다. 시범은 별도 파티를 사용하며 플레이어의 HP·기술 PP·
돈·아이템을 소비하지 않습니다. 시범의 비버니를 플레이어에게 지급하지 않습니다.
그 뒤 풀숲 조우가 활성화됩니다.

40개 플레이 검사를 통과했습니다. 실제 출입과 근접 트리거, 보상 중복 방지, 조작 복귀, 두 포켓몬의 전투 화면 진입,
메모리 내 저장/복원과 북쪽 경계까지 직접 걸어가는 경로를 검사했습니다.
포획 결과 문구는 네 번의 흔들림과 성공 효과 이후 한 번만 전달됨을 확인했습니다.
야외 경계의 추가 보행 검사는 [별도 보고서](connection_verification.json)에 보관합니다.
사용자 저장 파일이나 온라인 계정은 수정하지 않았습니다.

비버니는 도입 대사 전에 배치하고 전투 전환 중에 숨겨, 복귀 화면에 남지 않게 했습니다.
풀은 6개 합친 메시로 만들었고, 지형은 길과 주변의 높이 차이를 낮췄습니다.
포획 시범 시작 시 대화 카메라를 해제하고 종료 후 대화 샷을 다시 잡습니다.
풀의 가장자리 빛에는 잎 색을 반영해 흰색으로 날아가는 현상을 줄였습니다.

202번도로의 나머지 트레이너, 축복시티와 물건 전달, 무쇠시티·동굴 이후 챕터는
아직 구현 범위에 포함되지 않습니다. DP의 사건 순서를 따르되 맵 전체는
원작 지형을 그대로 재현한 상태가 아닙니다.
