# 집 시작·대화·현관 검증

새 게임은 TV 앞에서 시작하며, 이름 입력은 연구소의 마박사 대화에서 한 번만 표시됩니다.
실내 4종에 돌출 현관을 추가했고, 용식의 어머니는 플레이어 앞에서 거리를 두고 멈춥니다.
대화창은 반투명 검정 띠와 작은 이름표를 사용하며, 인물은 별도 초상화로 표시합니다.
장면 전환은 검정 화면의 알파값만 변경합니다.
