# 스타팅 전 찌르꼬 연출

가방 대화부터 찌르꼬 접근까지 같은 카메라 구도를 유지합니다. 반복 회전·확대 없이
플레이어와 용식 주변에서 일어나는 일을 함께 보여줍니다.

찌르꼬 네 마리가 약 4.2m/s로 총총 다가온 뒤 서로 다른 위치에서 감속해 멈춥니다.
발걸음은 실제 이동 속도에 맞춰 짧게 들썩이며, 멈추면 지면 높이로 복구합니다.
접근 지점은 마른 지면과 완전한 보행 경로를 확인하고 선택합니다.

검사는 실제 대화 UI, 스타팅 선택과 첫 전투, 박사의 복귀까지 이어집니다.
찌르꼬 네 마리 각각의 이동 거리와 최고 속도, 카메라 위치도 기록합니다.
검사 시작 시 문지기 통과 등 이전 사건의 상태를 실제 진행과 동일하게 설정합니다.

- [플레이 검사](verification.json)
- 재생: Tools > Poké Lab > Repair > Play Test Starter Sequence

최종 재생: 에피소드 3개 완료, 실패 0. 찌르꼬 네 마리의 접근은 약 2.06초였으며,
각각 2.01 / 2.63 / 6.49 / 2.05m 이동했습니다. 길을 돌아오는 개체도 보행 경로를
따라 움직입니다. 최고 속도는 3.54–4.67m/s로 기록됐습니다.
