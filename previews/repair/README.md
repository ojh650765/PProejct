# Unity / Blender 수정 확인

2026-09-17, Unity 6000.3.6f1, `grayling` 작업 공간에서 확인했습니다.

## 건물과 내부

마을의 건물 9채는 Blender에서 다시 만든 건물 5종을 사용합니다. 문 위치와
진입 지점을 맞췄으며, 집·연구소·포켓몬센터 내부에는 가구 메시와 충돌을 배치했습니다.
플레이어 집은 전용 내부를 사용하고, 나머지 주택 6채는 하나의 내부 씬을 공유합니다.
나올 때는 들어간 건물로 돌아갑니다.

- [주택 내부](../Interior_House_play.png): 침대, 주방, 책장, 식탁, 소파.
- [포켓몬센터 내부](../Interior_PokeCentre_play.png): 접수대, 회복 기계, PC, 대기 공간.
- [연구소 연출](../story/029.png): 책장, 실험대, 캐비닛, 박사와 도감 대화.
- [스타팅 등장](../story/023_starter.png): 모부기 위치, 조명, 스프라이트 픽셀 표시 수정.

## 검사 결과

- [기존 연출 9개 연속 재생](story_sequences_play.json): 모두 완료, 실패 0.
  실제 대화/선택 UI와 전투를 진행하고 조작 복귀 및 친구의 가방 옆 배치를 검사했습니다.
  라이벌 전투는 검사에서 직접 실행하므로 이 결과가 이후 스토리 연결까지 보장하지는 않습니다.
- [출입·수집·이동 검사](building_doors_play.json): 16개 통과.
  건물 9채 왕복, 아이템 5개 실제 상호작용과 중복 지급 방지, 다리 횡단,
  센터 HP/PP 회복 및 씬 이동 중 플레이어 데이터 유지.
- [월드 생성 검사](world_repair_verification.json): 10개 통과.
- [지면 판정 EditMode 검사](editmode_tests.json): 4개 통과.
- `python Tools/Story/validate_story.py`: 에피소드 13개, 샷 12개, 타임라인 3개 참조 검사 통과.

게임 데이터만 씬 사이에 유지하도록 바꿔 이전 맵의 카메라/대화 제어기가
연구소까지 따라와 중복되는 문제를 해결했습니다. 마지막 연속 재생의 연구소 화면도 확인했습니다.
